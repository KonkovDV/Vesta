# Claims

If a sentence in `README.md` disagrees with this file or with [limitations.md](limitations.md), this file and the limitations win.

These rows are claims about this source tree. They are not a deployment report and not a model score.

| ID | Claim | Where it is checked |
| --- | --- | --- |
| C1 | One process listens. `src/index.ts` calls `runKernel()`. Importing the package does not listen. | `docs/architecture.md` |
| C2 | A product pins a 40-character commit. A branch name is not a pin. | [adr/0001-kernel-as-package.md](adr/0001-kernel-as-package.md). A git install of `e6814bb` from a local clone ran (MP-K5); an install from github.com has not been run. |
| C3 | This cut exports `ICronService` and `ICronJobRepository`. `runKernel()` does not start a cron timer and performs no one-shot wake-up; `overdueSlotDecision` is not in this tree. Housekeeping still starts outside tests: the outbox poll, and an hourly purge of thoughts older than 24 hours. | `src/domain/scheduling/cron-service.port.ts`. `src/kernel.ts` re-exports the port. `src/infrastructure/memory/memory-cleanup.service.ts`. MP-K9. |
| C4 | A tool body that requires approval does not run unless the call has `approvalGranted`. The agent loop sets that flag after a recorded approval. A batch records `ask` and skips the body. The policy sees the validated arguments the body receives. | `src/application/agents/services/ToolRegistry.ts`, `src/application/agents/AgentRunService.ts`, `src/infrastructure/agents/BatchToolExecutorAdapter.ts`. `tests/unit/tool-registry.test.ts`. |
| C8 | One executor writes a run at a time. Every executor write carries the stream version it read; a cancel or a person's decision in between is skipped over, any other write means a second executor, and this one stops with `AgentRunConflictError` (or returns the result if that executor finished the run). So one tool call runs its body once, and a run has one model step per step and one `AgentRunFinished`. `ToolCallStarted` carries a lease (`toolLeaseMs`, default 15 min): while it lasts a resume elsewhere does not touch the run; after it the call is journaled as `outcome_unknown`, not run again. | `tests/unit/agent-run-service.test.ts`, `tests/integration/agent-run-postgres.test.ts`. |
| C9 | A kernel extension cannot replace or remove a registered token through the container it receives. Extension code runs in the same process with full privileges: it can still mutate an object it resolves. This is a guard against mistakes, not a sandbox. | `src/kernel.ts` (`createExtensionContainer`), `tests/unit/kernel-extensions.test.ts`. |
| C10 | A tool with external effects (exec, writes, messages, browser, sessions, automation) waits for a person by default; the decision is recorded with its author and the arguments hash, and the run resumes. An extension can add constraints, not remove them. | `tests/unit/tool-policy-service.test.ts`, `tests/unit/agent-run-routes.test.ts`. |
| C11 | `getCommittedEventsAfter` returns every committed event once, in commit order, including one whose transaction drew a lower gsn and committed later. | `tests/integration/event-commit-order.test.ts`. |
| C5 | The outbox hands each row to the bus at least once. A crash between the bus accept and the published mark leaves the row leased, then the worker tries again. A failed row waits for its backoff; versions of one aggregate leave in order. The default bus is Redis Pub/Sub: a message with no subscriber is accepted and lost (MP-K22). `EVENT_BUS_TRANSPORT=streams` keeps the entry until a consumer group acknowledges it. A consumer that starts later still reads it. A read that is not acknowledged is delivered again. After the handler finishes, `processed_events` records the id so that consumer does not run it again. | `src/infrastructure/events/postgres-outbox.ts`, `tests/integration/outbox-delivery.test.ts`, `tests/integration/redis-streams-bus.test.ts`. The kernel does not claim exactly-once across a network. The default stays Pub/Sub. |
| C6 | The kernel ships one forward file, `001_consolidated.sql`. It creates `tx_id`, the outbox lease columns, and `event_store.consumer_cursors`. A matching checksum skips it. A failed file does not store a checksum and stops the run. A database that already stored an older checksum of this filename refuses the new file. | `src/infrastructure/database/migrations/001_consolidated.sql`, `src/infrastructure/database/migration-runner.ts`, `tests/unit/migration-runner.test.ts`; CI applies it twice on pgvector/PostgreSQL 17. |
| C12 | Sales, HR, healthcare, and ingest routes answer 403 unless the key has `sales.use`, `hr.use`, `healthcare.use`, or `memory.ingest`. MRI review and finalize also need `healthcare.review`. | `tests/unit/product-route-scopes.test.ts`. MP-K32. Keys from `BFF_API_KEY` and `BFF_API_KEYS_CSV` have no scopes. |
| C13 | With `USE_MOCK_AI` off, `SELF_LLM_URL` plus `SELF_LLM_MODEL` selects an OpenAI-compatible chat model at that URL with `/v1` added when it is missing. An empty model name throws. `USE_MOCK_AI=true` does not call that URL. | `tests/unit/chat-model-selection.test.ts`. This is not a claim that the model answers correctly. MP-K42. |
| C14 | On the integration job the kernel resolves every registered token. A failure whose name is outside `tests/gates/resolve-all-budget.json` fails CI. A route that is not in `tests/gates/public-routes.json` answers 401 or 403 without a key. A 404 is not that check. | `tests/unit/ci-gates.test.ts` checks the comparison and the Express walker. The live walk is `scripts/ci-resolve-all.cjs` and `scripts/ci-routes-auth.cjs` in `.github/workflows/ci.yml`. MP-K35. `/health/migration` and `POST /ent/slack/slash` are on the public list. |
| C7 | Selected outbound calls connect to the addresses `pinUrl` just returned. A later DNS answer is not used for that socket. A redirect is pinned again. | `src/infrastructure/http/SsrfPinnedHttpClient.ts`. Call sites in this tree: ingestion in `memory.module.ts`, `A2AX402PaymentAdapters.ts`, `ContainerRegistryAdapter.ts`, `A2ATaskRunnerAdapter.ts`, `A2AStreamTransportAdapter.ts`, and outbound MCP over HTTP (`McpToolConsumerAdapter`, `tests/unit/mcp-consumer-pin.test.ts`). The `web-browser` plugin checks but Chrome resolves names itself. A validator without `pinUrl` is not this claim. |
